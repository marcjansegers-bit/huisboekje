# Begroting

1. Kopieer `begroting-sjabloon.csv` naar `JJJJ.csv`.
2. Vul per regel het bedrag in; reken jaarlijkse posten om naar `bedrag_per_maand` (÷ 12) en **reserveer** die maandelijks.
3. Doel: inkomen − uitgaven − sparen = € 0 (elke euro een bestemming).
4. Controleer elke maand de werkelijke uitgaven in `03-transacties/` tegen deze begroting.

Tip: vergelijk je bedragen met de referentiebedragen van het [Nibud](https://www.nibud.nl).
