# Checklist aangifte inkomstenbelasting

Belastingjaar: ____  ·  Aangifte gedaan op: ____  ·  Fiscaal partner: ja / nee

## 1. Voorbereiden (januari–februari)

- [ ] DigiD werkt (en machtiging partner, indien van toepassing)
- [ ] Jaaropgave(n) werkgever / uitkeringsinstantie / pensioenfonds
- [ ] Jaaroverzicht hypotheek (rente, restschuld op 1 jan en 31 dec)
- [ ] WOZ-beschikking (waarde peildatum 1 januari vorig jaar)
- [ ] Bankoverzichten saldo 1 januari (alle rekeningen, ook buitenland)
- [ ] Beleggingsoverzichten waarde 1 januari
- [ ] Overzicht schulden 1 januari (studieschuld, leningen)
- [ ] Bewijzen giften (ANBI-status gecontroleerd op belastingdienst.nl)
- [ ] Bewijzen specifieke zorgkosten
- [ ] Jaaroverzicht lijfrente / Jaarruimte berekening
- [ ] Beschikkingen toeslagen
- [ ] Voorlopige aanslag / teruggaaf van dit jaar

## 2. Aangifte invullen (vanaf 1 maart)

**Persoonlijk**
- [ ] Persoonlijke gegevens en fiscaal partnerschap kloppen
- [ ] Kies verdeling gezamenlijke posten met partner (meestal zo voordelig mogelijk — het programma rekent dit uit)

**Box 1 – Werk en woning**
- [ ] Loon, uitkering, pensioen: vergelijk vooraf ingevulde gegevens met jaaropgaven
- [ ] Ingehouden loonheffing klopt
- [ ] Overige werkzaamheden (freelance, verhuur roerende zaken)
- [ ] Eigen woning: WOZ-waarde → eigenwoningforfait
- [ ] Hypotheekrente (alleen eigenwoningschuld, annuïtair/lineair afgelost)
- [ ] Aftrekposten: zie [`aftrekposten.md`](aftrekposten.md)
- [ ] Lijfrentepremie (binnen jaarruimte/reserveringsruimte)

**Box 2 – Aanmerkelijk belang**
- [ ] Alleen bij ≥ 5% aandelen in een bv

**Box 3 – Sparen en beleggen** (peildatum 1 januari)
- [ ] Banktegoeden (incl. kinderrekeningen, minderjarige kinderen tellen bij ouders)
- [ ] Beleggingen, crypto
- [ ] Overige bezittingen (tweede woning, uitgeleend geld)
- [ ] Schulden (bijv. studieschuld; let op drempel)
- [ ] Werkelijk rendement lager dan forfaitair? Overweeg tegenbewijs (opgaaf werkelijk rendement)

**Buitenland**
- [ ] Buitenlandse rekeningen/inkomsten opgegeven

## 3. Controleren en versturen

- [ ] Uitkomst vergelijken met vorig jaar — grote verschillen verklaard?
- [ ] Concept-pdf opgeslagen in je eigen archief
- [ ] Verzonden vóór **1 mei** (of uitstel aangevraagd)
- [ ] Bevestiging opgeslagen

## 4. Na de aangifte

- [ ] Voorlopige aanslag volgend jaar aanpassen als inkomen/situatie anders is
- [ ] Toeslagen aanpassen op nieuw verwacht inkomen
- [ ] Definitieve aanslag ontvangen op ____  → gecontroleerd tegen aangifte
- [ ] Bezwaar nodig? Binnen **6 weken** na dagtekening
- [ ] Alles genoteerd in `jaren/JJJJ/samenvatting.md`
