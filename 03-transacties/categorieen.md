# Categorieën

Gebruik deze vaste lijst zodat maanden en jaren vergelijkbaar blijven. Pas aan waar nodig, maar wijzig liever niet halverwege het jaar.

| Categorie | Subcategorieën |
|---|---|
| Inkomen | Salaris, Vakantiegeld, Uitkering, Toeslagen, Kinderbijslag, Teruggave belasting, Rente/dividend, Overig |
| Wonen | Huur/hypotheek, Onderhoud, Gemeentelijke belastingen, Waterschap, VvE |
| Vaste lasten | Energie, Water, Internet/tv, Mobiel |
| Verzekeringen | Zorg, Inboedel, Opstal, Aansprakelijkheid, Auto, Rechtsbijstand, Overlijdensrisico |
| Vervoer | Brandstof/laden, Onderhoud, Wegenbelasting, OV, Parkeren, Fiets |
| Huishouden | Boodschappen, Drogist, Huisdieren, Inrichting |
| Persoonlijk | Kleding, Kapper, Zorgkosten, Eigen risico, Opleiding |
| Kinderen | Opvang, School, Sport, Zakgeld |
| Vrije tijd | Uit eten, Abonnementen, Hobby, Vakantie, Cadeaus |
| Giften | Eenmalige gift, Periodieke gift |
| Belastingen | Inkomstenbelasting, Naheffing, Boete |
| Sparen & beleggen | Buffer, Spaardoel, Beleggen, Pensioen/lijfrente, Extra aflossing |
| Overboekingen | Eigen rekeningen (niet meetellen als uitgave) |

## Kolom `fiscaal_relevant`

Zet op **ja** bij alles wat mogelijk in de aangifte terugkomt: giften, specifieke zorgkosten, hypotheekrente, lijfrente-inleg, studiekosten, alimentatie. Zo heb je in maart alles bij elkaar.
