# Vermogen

Leg elk jaar op **1 januari** vast wat je bezit en schuldig bent. Dat is de peildatum voor box 3 en voor de vermogensgrens van toeslagen.

1. Kopieer `vermogen-sjabloon.csv` naar `JJJJ-01-01.csv`.
2. Vul per rekening de waarde in (alleen laatste 4 cijfers van rekeningnummers).
3. Neem het totaal over in het jaaroverzicht (`01-overzicht/`).
